PCL Light 1.0.0 热修复 4。

## 降低图片内存峰值

- Minecraft 服务器图标按控件显示尺寸解码，最长边限制为 128 像素，并保持原图比例；常规 64×64 图标不放大。
- Base64 图标解析改为首个分隔符切片，避免 `Split` 产生的临时数组和多余字符串。
- 增加横向、纵向大图与常规图标的解码回归测试。

## 缩小发布文件

- 不再将三份未使用的旧版备份图标嵌入单文件程序。
- x64 单文件从 17.05 MiB 降到 16.83 MiB，保留 `.NET 6` framework-dependent 发布方式和 Windows 7 SP1 兼容目标。
- 本轮内存采样波动较大，未确认可重复的空闲内存下降，不发布内存改善数值。

## 签名

- x64 与 ARM64 发布文件使用 PCL Lite 代码签名证书进行 Authenticode SHA-256 签名，并加 RFC 3161 时间戳。
- 随 release 附上公开 `.cer` 证书供核验。
